# D-009 check: AUC with and without duplicate rows

Required by D-009, run at the evaluation stage (D-033). The frozen, tested scorecard (fingerprints checked against the test lock) scores **valid** and **test**. Nothing is refitted or tuned. This is a recorded addendum in the test lock, not a second evaluation. Generated by `python -m scorecard.evaluation.duplicates`.

**Definition (D-009).** Drop valid/test rows whose 10 feature values exactly match a train row, and keep one copy of rows repeated inside the split. Applied to:

- **raw values** (primary): the data as it arrived, the closest proxy for the same applicant;
- **cleaned values** (stricter): the model's inputs. Cleaning turns placeholders into missing, so rows that differed only in a placeholder now count as twins.

Scored with the deployed PD (integer score -> master scale, D-016), as in the test-evaluation headline, so `auc_all_rows` matches that report.

| split | matched on | rows | twin_in_train | repeat_in_split | removed | auc_all_rows | auc_without_duplicates | auc_change | gini_change |
|---|---|---|---|---|---|---|---|---|---|
| valid | raw values | 22,500 | 126 | 23 | 130 | 0.8592 | 0.8592 | -0.00004 | -0.00009 |
| valid | cleaned values | 22,500 | 436 | 99 | 456 | 0.8592 | 0.8588 | -0.00044 | -0.00089 |
| test | raw values | 22,500 | 129 | 24 | 135 | 0.8602 | 0.8601 | -0.00008 | -0.00017 |
| test | cleaned values | 22,500 | 404 | 91 | 427 | 0.8602 | 0.8596 | -0.00058 | -0.00117 |

**Result.** The largest absolute AUC change is **0.0006**, below the 0.005 materiality threshold (**Assumption**, config `duplicates`), so the duplicates do not inflate the reported performance. D-009's choice to keep them stands. For scale: the test AUC's 95% bootstrap interval in [test_evaluation.md](test_evaluation.md) is about 0.02 wide.
